## 📌 Proje Hakkında

Tekerlekli savunma araçları için aks, transfer kutusu ve şasi üreten BASE için geliştirdiğim site ve IDEX 2027 fuar önerisi. Three.js ile platform görselleştirmeleri, çöl / arktik iklim değiştirici, aktarma organı konfigüratörü, canlı prototip dashboard'u ve deneyim alanı konsepti içeriyor.
